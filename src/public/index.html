🎥 Reolink Camera Streams

Live monitoring of 7 camera feeds

📋 Setup Instructions

1. Configure Secrets

Add the required secrets to your Worker:

npx wrangler secret put NVR_PASSWORD
# Enter: @codecam22

npx wrangler secret put CLOUDFLARE_API_TOKEN
# Create a token at: https://dash.cloudflare.com/profile/api-tokens
# Permissions needed: Stream:Edit

npx wrangler secret put CLOUDFLARE_ACCOUNT_ID
# Your Account ID from Cloudflare dashboard

2. Create KV Namespace

npx wrangler kv:namespace create STREAM_CACHE
npx wrangler kv:namespace create STREAM_CACHE --preview

Update the kv_namespaces binding in wrangler.jsonc with the returned IDs.

3. Configure RTSP Stream Forwarding

You'll need to set up stream forwarding from your Reolink NVR to Cloudflare Stream using one of these methods:

Option A: Using FFmpeg (Recommended)

Run FFmpeg on a server that can access your NVR:

# For each camera (run 7 instances):
ffmpeg -rtsp_transport tcp \
  -i rtsp://hwmnbn:@codecam22@hwmnbn.myddns.me:554/h264Preview_01_main \
  -c:v copy -f flv [RTMP_INGEST_URL]

# Camera URLs follow pattern:
# Camera 1: rtsp://hwmnbn:@codecam22@hwmnbn.myddns.me:554/h264Preview_01_main
# Camera 2: rtsp://hwmnbn:@codecam22@hwmnbn.myddns.me:554/h264Preview_02_main
# ... etc (change _01_, _02_, etc.)

Option B: Using Cloudflare Tunnel

Create a tunnel to forward streams securely to Cloudflare Stream.

4. Initialize Streams

Click the "Initialize Streams" button above. This will:

  1. Create 7 Cloudflare Stream Live inputs
  2. Generate RTMP ingest URLs for each camera
  3. Display the URLs you need to configure in FFmpeg

5. Start Streaming

Use the RTMP URLs from step 4 to configure your FFmpeg instances or streaming software.
